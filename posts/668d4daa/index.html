📁 文件与目录操作

🎯 功能 🔧 命令 💡 实用示例 📋 说明
📋 列出文件 ls / ls -la / ls -lh ls -laht 显示详细信息、隐藏文件、人类可读大小
🔄 切换目录 cd ~ / cd - / cd .. cd /var/www 回家目录、返回上次目录、上级目录
📂 创建目录 mkdir dir / mkdir -p path/dir mkdir -p /tmp/test/sub 创建目录、创建多级目录
🗑️ 删除目录 rmdir dir / rm -rf dir rm -rf /tmp/test 删除空目录、强制递归删除
📄 文件操作 cp src dst / mv src dst cp -r dir1 dir2 复制、移动/重命名，-r递归复制
🔍 查找文件 find /path -name "*.txt" find . -type f -name "*.log" 按名称、类型查找
👀 查看内容 cat file / less file / tail -f file tail -100f /var/log/syslog 查看全部、分页查看、实时跟踪

👥 用户与权限

🎯 功能 🔧 命令 💡 实用示例 📋 说明
➕ 添加用户 sudo adduser alice sudo adduser alice --ingroup sudo 交互式创建用户，可指定用户组
🔑 修改密码 passwd / sudo passwd alice sudo passwd -e alice 修改密码，-e强制下次登录修改
🔐 修改权限 chmod 755 file / chmod +x script.sh chmod -R 644 /var/www 数字或符号模式，-R递归
👤 修改属主 sudo chown user:group file sudo chown -R www-data:www-data /var/www 同时修改用户和组
🔓 提权运行 sudo cmd / sudo -i sudo -u www-data cmd 单条命令或切换到root，可指定用户

🎯 权限数字说明

数字 权限 含义
7 rwx 读+写+执行
6 rw- 读+写
5 r-x 读+执行
4 r-- 只读
0 --- 无权限

🎯 功能 🔧 命令 💡 实用示例 📋 说明
▶️ 启动服务 sudo systemctl start nginx sudo systemctl start nginx 立即启动服务
⏹️ 停止服务 sudo systemctl stop nginx sudo systemctl stop nginx 立即停止服务
🔄 重启服务 sudo systemctl restart nginx sudo systemctl restart nginx 重启服务
📊 查看状态 systemctl status nginx systemctl status nginx --no-pager 显示服务详细状态
🚀 开机自启 sudo systemctl enable nginx sudo systemctl enable nginx 设置开机自动启动
📜 查看日志 journalctl -u nginx.service journalctl -u nginx -f 查看服务日志，-f实时跟踪
