graph LR

🎯 功能 🔧 命令 💡 实用示例 📋 说明
👤 设置用户名 git config --global user.name "Your Name" git config --global user.name "张三" 设置全局用户名

🎨 设置编辑器 git config --global core.editor vim git config --global core.editor nano 设置默认文本编辑器
📊 查看配置 git config --list git config --list --global 查看所有配置
📝 初始化仓库 git init git init myproject 初始化新仓库
🔍 查看帮助 git help <command> git help commit 查看命令帮助

graph LR
    A[创建分支] --> B[开发功能]
    B --> C[提交更改]
    C --> D[推送分支]
    D --> E[创建PR]

🎯 功能 🔧 命令 💡 实用示例 📋 说明
🌿 创建分支 git branch <branch> git branch feature-login 创建新分支
🔄 切换分支 git checkout <branch> git checkout develop 切换到指定分支
🚀 创建并切换 git checkout -b <branch> git checkout -b feature/api 创建并切换到新分支
📋 列出分支 git branch git branch -r 列出本地/远程分支
🗑️ 删除分支 git branch -d <branch> git branch -D feature-old 删除分支
🔄 重命名分支 git branch -m <old> <new> git branch -m master main 重命名当前分支

🎯 分支操作高级技巧

🌐 远程操作

🎯 功能 🔧 命令 💡 实用示例 📋 说明
🔗 添加远程 git remote add <name> <url> git remote add upstream https://github.com/original/repo.git 添加远程仓库
📤 推送代码 git push <remote> <branch> git push origin master 推送代码到远程
📥 拉取代码 git pull <remote> <branch> git pull origin develop 拉取远程代码
🔄 获取代码 git fetch <remote> git fetch --all 获取远程更新
🔗 查看远程 git remote -v git remote show origin 查看远程仓库信息

🎯 远程操作实战

📝 提交管理

🎯 功能 🔧 命令 💡 实用示例 📋 说明
➕ 添加文件 git add <file> git add . / git add -A 添加文件到暂存区
💾 提交更改 git commit -m "message" git commit -m "feat: add login feature" 提交暂存区更改
📝 修改提交 git commit --amend git commit --amend -m "new message" 修改最后一次提交
🗑️ 移除文件 git rm <file> git rm --cached file 从版本控制中移除文件
🔄 移动文件 git mv <old> <new> git mv old.txt new.txt 重命名或移动文件

🎯 提交规范与最佳实践

🔀 合并与重置

🎯 功能 🔧 命令 💡 实用示例 📋 说明
🔀 合并分支 git merge <branch> git merge feature-branch 合并指定分支
🔄 变基操作 git rebase <branch> git rebase master 将当前分支变基
⏪ 重置提交 git reset <commit> git reset --hard HEAD~1 重置到指定提交
🔄 撤销更改 git revert <commit> git revert abc123 撤销指定提交
📝 保存进度 git stash git stash push -m "work in progress" 保存当前工作进度

🏷️ 标签管理

🎯 功能 🔧 命令 💡 实用示例 📋 说明
🏷️ 创建标签 git tag <tag> git tag v1.0.0 创建轻量标签
🏷️ 创建附注标签 git tag -a <tag> -m "message" git tag -a v1.0.0 -m "First stable release" 创建带注释的标签
📋 列出标签 git tag git tag -l "v1.*" 列出所有标签
🔄 推送标签 git push origin <tag> git push origin --tags 推送标签到远程
🗑️ 删除标签 git tag -d <tag> git tag -d v1.0.0 删除本地标签

🔍 调试与回退

🎯 功能 🔧 命令 💡 实用示例 📋 说明
🔍 查看差异 git diff git diff HEAD~2..HEAD 查看文件差异
📋 查看提交详情 git show <commit> git show abc123 查看提交详细信息
⏪ 回退文件 git checkout <file> git checkout HEAD~1 file.txt 回退文件到指定版本
🔄 恢复删除文件 git checkout <commit> -- <file> git checkout HEAD~2 -- deleted.txt 恢复已删除的文件
📝 查看引用日志 git reflog git reflog --date=iso 查看操作历史
