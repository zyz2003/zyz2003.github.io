📦 镜像相关命令

命令 用途 示例 说明
docker search 🔍 搜索镜像 docker search nginx 在Docker Hub搜索nginx镜像
docker pull ⬇️ 拉取镜像 docker pull nginx:latest 下载最新版nginx镜像
docker images 📋 列出镜像 docker images 显示本地所有镜像
docker rmi 🗑️ 删除镜像 docker rmi nginx:latest 删除nginx镜像
docker build 🏗️ 构建镜像 docker build -t myapp:1.0 . 使用Dockerfile构建镜像

🎯 镜像命令详解

🔍 搜索镜像

  • 示例: docker search nginx
  • 说明: 在Docker Hub上搜索相关镜像
  • 技巧: 可以加 --filter=stars=100 过滤高质量镜像

⬇️ 拉取镜像

  • 示例: docker pull nginx:latest
  • 说明: 从Docker Hub拉取指定版本的镜像
  • 常用标签: latest, alpine, stable

📋 查看本地镜像

  • 示例: docker images
  • 输出说明:
    • REPOSITORY: 镜像名称
    • TAG: 版本标签
    • IMAGE ID: 镜像ID
    • SIZE: 镜像大小

🚀 容器相关命令

命令类别 命令 示例 用途
运行 docker run docker run -d -p 8080:80 nginx 🚀 运行新容器
列表 docker ps docker ps -a 📋 查看容器列表
停止 docker stop docker stop web ⏹️ 停止容器
启动 docker start docker start web ▶️ 启动容器
重启 docker restart docker restart web 🔄 重启容器
删除 docker rm docker rm web 🗑️ 删除容器
日志 docker logs docker logs -f web 📜 查看日志
进入 docker exec docker exec -it web bash 🔍 进入容器

🎯 容器操作详解

🚀 运行容器（核心命令）

选项 说明 示例
-d 🌙 后台运行 docker run -d nginx
-p 🔗 端口映射 docker run -p 8080:80 nginx
-v 📁 卷挂载 docker run -v /host:/container nginx
--name 🏷️ 容器命名 docker run --name web nginx
--restart 🔄 重启策略 docker run --restart=always nginx

🌐 网络相关命令

命令 用途 示例 说明

docker network create 🆕 创建网络 docker network create mynet 创建自定义网络
docker network rm 🗑️ 删除网络 docker network rm mynet 删除网络
docker network inspect 🔍 查看详情 docker network inspect mynet 网络详细信息

🎯 网络操作详解

🆕 创建自定义网络

  • 示例: docker network create mynetwork
  • 选项:
    • --driver bridge: 桥接模式（默认）
    • --subnet: 指定子网
    • --ip-range: IP范围

🎯 常用场景速查表

场景 命令组合
快速启动Web服务 docker run -d -p 80:80 --name web nginx
运行MySQL docker run -d -p 3306:3306 -e MYSQL_ROOT_PASSWORD=123456 mysql:5.7
进入容器调试 docker exec -it [容器ID] /bin/bash
查看实时日志 docker logs -f [容器ID]
清理所有容器 docker rm -f $(docker ps -aq)
清理所有镜像 docker rmi $(docker images -q)
